# FoodShare Network

Sistema de Gestión de Recursos Alimentarios (ODS 2 — Hambre Cero) 
Proyecto Integrador de Programación Orientada a Objetos — UVM

## Descripción
Plataforma que conecta los excedentes de comida de restaurantes y comedores
con fundaciones y organizaciones benéficas, para reducir el desperdicio de
alimentos. Usuarios: Restaurante (donante), Fundación (receptor) y Administrador.

## Tecnologías
- Python 3
- Programación Orientada a Objetos (herencia, composición, encapsulamiento)
- Metodología Scrum

## Cómo ejecutarlo
python proyecto.py

## Estado actual (Fase 1)
Prototipo con las clases Usuario, Restaurante y Donacion.
Pendiente: Fundacion, Administrador, Alimento, Nutriente e interfaz gráfica.
